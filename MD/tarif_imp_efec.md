No exactamente. Valor gravable es la *base imponible* — el monto sobre el cual se *aplica* el arancel, no lo que se recaudaría.

Para recaudar necesitas dos cosas:
1. La base: **valor gravable** (¿sobre cuánto se cobra?)
2. La tasa: **tasa estatutaria** (¿a qué porcentaje?)

Lo que se recaudaría = valor gravable × tasa estatutaria = **derechos**.

Un ejemplo concreto con números redondos:

| Concepto | Valor |
|---|---|
| Valor importado total | 100 |
| Valor gravable (no exento) | 25 |
| Valor exento (USMCA, etc.) | 75 |
| Tasa estatutaria | 25% |
| Derechos cobrados | 6.25 |
| Tasa implícita | 25% (= 25/100) |
| Tasa efectiva | 6.25% (= 6.25/100) |

Entonces la tasa implícita responde a "¿qué fracción del valor total está expuesta al arancel?", no "¿cuánto se recaudaría?". Es una medida de cobertura de las exenciones, no de recaudación.
